# Математические формулы
## Площадь
- Круг: S = πR²
- Прямоугольник: S = ab
- Квадрат: S = a²
- Треугольник: S = ah / 2
## Периметр
- Круг: P = 2πR
- Прямоугольник: P = 2a + 2b
- Квадрат: P = 4a
- Треугольник: P = a + b + c

## Общее описание
Библиотека Geometric Lib позволяет вычислять площадь и периметр для основных геометрических фигур: круга, квадрата, прямоугольника и треугольника.

## Описание функций

### Круг (circle.py)
- area(r): Принимает радиус r, возвращает площадь круга.
Пример вызова: area(5)

- perimeter(r): Принимает радиус r, возвращает длину окружности.
Пример вызова: perimeter(5)

### Квадрат (square.py)
- area(a): Принимает сторону a, возвращает площадь квадрата.
Пример вызова: area(5)

- perimeter(a): Принимает сторону a, возвращает периметр квадрата.
Пример вызова: perimeter(5)

### Прямоугольник (rectangle.py)
- area(a, b): Принимает стороны a и b, возвращает площадь прямоугольника.
Пример вызова: area(3, 5)

- perimeter(a, b): Принимает стороны a и b, возвращает периметр прямоугольника.
Пример вызова: perimeter(3, 5)

### Треугольник (triangle.py)
- area(a, h): Принимает сторону a и высоту h, возвращает площадь треугольника.
Пример вызова: area(3, 4)

- perimeter(a, b, c): Принимает стороны a, b и c, возвращает периметр треугольника.
Пример вызова: perimeter(3, 4, 5)
